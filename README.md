# تفسير سورة البقرة

تطبيق ويب تقدّمي (PWA) عربي يُثبَّت على الهاتف من المتصفح، يرتّب تسجيلات تفسير سورة البقرة حسب الآيات.

- شجرة كاملة لآيات السورة الـ286: الجزء ← صفحة المصحف ← الآية، مع عدد التسجيلات لكل منها.
- مشغّل صوتي بسرعات 0.75× حتى 2×، تقديم ورجوع 15 ثانية، ويتذكّر موضع التوقف لكل تسجيل.
- عند التشغيل تظهر صفحة/صفحات المصحف المرتبطة بآيات التسجيل (مصحف المدينة، الصفحات 2–49).
- مشاركة رابط التسجيل أو الملف الصوتي نفسه.
- أكثر من تسجيل للآية الواحدة، وتُرتَّب التسجيلات تصاعدياً حسب ترتيب الآيات.
- يعمل دون اتصال بعد أول فتح (الواجهة والآيات وصفحات المصحف).

## الحسابات

- **الضيوف:** يتصفحون ويستمعون ويشاركون بدون أي تسجيل دخول.
- **الأدمن:** من "دخول الأدمن" باسم المستخدم `admin` وكلمة المرور (حساب Firebase Auth بالبريد `admin@tafseer-albaqara.app`). عند أول دخول يُطلب مفتاح GitHub مرة واحدة (fine-grained token بصلاحية Contents: Read and write على هذا المستودع) ويُحفظ في Firestore في `admin/github`، ولا يقرؤه إلا حساب الأدمن (`firestore.rules`). بعدها يظهر زر ＋ لرفع تسجيل وتحديد آياته، فيُضاف الملف إلى `audio/` ويُحدَّث `data/clips.json` ويُنشر الموقع تلقائياً.

يمكن أيضاً إضافة تسجيل يدوياً بوضع الملف في `audio/` وإضافة سطر في `data/clips.json`:

```json
{"id": "135-137", "from": 135, "to": 137, "src": "audio/135-137.m4a", "title": "", "speaker": "", "duration": 600, "added": "2026-11-16"}
```

## الاستضافة

Firebase Hosting (خطة Spark المجانية)، والنشر تلقائي عند كل تحديث على `main` عبر `.github/workflows/deploy.yml`. يحتاج سراً في المستودع باسم `FIREBASE_SERVICE_ACCOUNT`، ومعرّف المشروع في `.firebaserc`.

## المصادر

- نص الآيات: حزمة [quran-json](https://www.npmjs.com/package/quran-json) (رواية حفص).
- أرقام الصفحات والأجزاء: حزمة [quran-meta](https://www.npmjs.com/package/quran-meta).
- صور صفحات المصحف: مصحف المدينة النبوية (مجمع الملك فهد لطباعة المصحف الشريف) عبر مستودع [GovarJabbar/Quran-PNG](https://github.com/GovarJabbar/Quran-PNG)، مضغوطة بصيغة WebP.
